# 非功能需求

## 文档定位
本文档记录闪记项目当前与近期需要明确的非功能需求，用于指导后续性能、稳定性、安全性、可维护性与兼容性相关工作。

## 当前非功能目标

### 可靠性
- 核心主线（登录、闪记、消息、合集、同步）需要具备可重复验证的最小闭环
- 关键路径错误需要通过统一错误响应与日志快速定位

### 可维护性
- 当前态、目标态、原型意图必须持续分离
- 所有接口、数据库、同步相关变更都要回写文档
- `docs/完整开发计划.md` 作为总计划源头持续维护

### 安全性
- token 不得明文持久化
- 认证接口、刷新接口、上传接口需要最小安全约束
- 本地示例密钥不得直接进入正式环境

### 性能与容量（当前阶段）
- 当前阶段先追求功能闭环与可验证性，不设激进性能指标
- 但需要避免明显低级问题：超大文件上传、无限错误重试、无控制的同步 payload

### 兼容性
- 当前客户端主线只要求 Android
- Web / iOS 暂不作为当前交付兼容目标

## 当前未明确但后续需要细化的非功能项
- 响应时间指标
- 并发与容量指标
- 数据保留与备份策略
- 正式环境 SLA / 告警指标

## 维护规则
- 当项目进入增强版或完整项目阶段时，应把本文件从“原则级”进一步细化为可量化指标
