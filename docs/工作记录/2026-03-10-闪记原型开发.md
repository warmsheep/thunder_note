## 二、完成功能清单

### 2.1 图片多选发送功能

**需求描述**：
用户点击发送图片时，可以选择多张图片，然后弹出预览框，显示已选择的图片，图片右上角有X可以取消选择，输入框可以输入文字，点击发送后文字和图片作为一条消息发送（图片在上，文字在下）。

**实现方案**：
- 新增图片选择器模态框（`image-picker-modal`）
- 使用隐藏的 `<input type="file" multiple>` 实现多选
- FileReader API 读取图片为 DataURL
- 预览网格展示已选图片，支持移除
- 消息类型扩展为 `mixed`，支持 `images` 数组 + `content` 文字

**涉及文件**：
- `thunder-note-prototype.html`：CSS样式、HTML结构、JavaScript逻辑

### 4.3 主题切换实现

```javascript
// 切换暗黑模式
function toggleDarkMode() {
  const isDark = document.getElementById('dark-mode-toggle').checked;
  if (isDark) {
    document.documentElement.classList.add('dark-mode');
    localStorage.setItem('darkMode', 'true');
  } else {
    document.documentElement.classList.remove('dark-mode');
    localStorage.setItem('darkMode', 'false');
  }
}

// 页面加载时恢复
function loadDarkModePreference() {
  if (localStorage.getItem('darkMode') === 'true') {
    document.documentElement.classList.add('dark-mode');
    document.getElementById('dark-mode-toggle').checked = true;
  }
}
```
