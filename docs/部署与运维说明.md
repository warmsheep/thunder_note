# 部署与运维说明

## 文档定位
本文档描述闪记当前已知的运行环境事实与后续需要补齐的部署运维约束，用于支持开发环境、测试环境与后续正式环境的搭建。

## 当前本地运行事实
### 后端依赖
- PostgreSQL
- Redis
- MinIO

### 当前关键配置
- 数据库：`jdbc:postgresql://localhost:5432/thunder_note`
- Redis：`localhost:6379`
- MinIO：`http://localhost:9000`
- 服务端口：`8080`

## 当前已知缺口
- 尚未形成明确的 dev / staging / prod 环境说明
- 尚未形成正式部署流程文档
- 尚未形成数据库迁移上线流程文档
- 尚未形成 Android 构建、签名、分发说明

## 推荐环境分层结构
- `application.yml`：共享基础配置
- `application-dev.yml`：本地开发配置
- `application-test.yml`：测试 / CI 配置
- `application-staging.yml`：预发布配置
- `application-prod.yml`：生产配置

说明：
- profile 配置应覆盖基础配置，而不是完全替代。
- secret、password、accessKey、secretKey 不应长期直接写入仓库配置文件。
- 如果后续引入环境变量或密钥托管，需要在本文件同步记录配置来源与优先级。

## 近期应补的运维能力
- 明确开发环境启动顺序
- 明确 Flyway 迁移执行规则
- 明确 MinIO bucket 初始化规则
- 明确生产环境不能直接使用示例密钥与本地默认配置

## 当前部署提醒
- `application.yml` 中包含本地默认配置与示例型敏感项，不能直接作为生产配置模板
- 当前仓库未发现 CI 工作流，说明构建发布链路尚未工程化
- Spring profile 的启用方式、属性覆盖顺序、密钥来源后续应固定成团队约定。

## 维护规则
- 配置项、端口、依赖服务、部署方式发生变化时，必须同步更新本文件
