# 浏览器自动化操作手册

## 问题描述

在 CentOS 7 服务器上运行 `browser-use` 或 Playwright 时，遇到以下问题：

```
Missing X server or $DISPLAY
ERROR: ui/ozone/platform/x11/ozone_platform_x11.cc:256] Missing X server or $DISPLAY
```

即使服务器有桌面环境（:0 显示），也无法打开可见浏览器窗口。

---

## 根因分析

1. **服务器环境**：CentOS 7，有桌面环境（用户 warmsheep 登录在 `:0`）
2. **问题1**：没有 Xvfb（虚拟 X 服务器）
3. **问题2**：以 root 用户运行时，无法访问用户桌面 `:0` 显示
4. **权限问题**：`browser-use` 是 root 安装的，普通用户无法执行

---

## 解决方案

### 方案一：安装 Xvfb（推荐用于无头服务器）

```bash
# CentOS/RHEL
yum install -y xorg-x11-server-Xvfb

# Ubuntu/Debian
apt-get install -y xvfb

# 使用 xvfb 运行
xvfb-run -a browser-use --browser real open "https://www.google.com"
```

### 方案二：使用已登录用户的桌面显示（服务器有桌面的情况）

```bash
# 方法1：直接运行 Chromium（需要知道用户名）
su - <用户名> -c "export DISPLAY=:0 && chromium-browser --new-window 'https://www.google.com'"

# 示例：用户是 warmsheep
su - warmsheep -c "export DISPLAY=:0 && chromium-browser --new-window 'https://www.google.com/search?q=今日金价'"
```

## 完整操作步骤

### 步骤1：检查服务器环境

```bash
# 查看当前用户和显示
who
# 输出示例：
# warmsheep :0           2026-03-11 15:00 (:0)

# 查看 X server 状态
ls -la /tmp/.X*
```

### 步骤2：如果是 root 用户，先安装必要工具

```bash
# 安装 Xvfb（无头模式需要）
yum install -y xorg-x11-server-Xvfb

# 复制 browser-use 到全局路径
cp /root/.nvm/versions/node/v22.10.0/bin/browser-use /usr/local/bin/
chmod +x /usr/local/bin/browser-use
```

### 步骤3：根据环境选择运行方式

#### 场景A：服务器有桌面，用户已登录

```bash
# 获取显示编号
who
# 假设输出: warmsheep :0

# 以该用户运行浏览器
su - warmsheep -c "export DISPLAY=:0 && chromium-browser --new-window 'https://www.google.com'"
```

#### 场景B：服务器无桌面（无头模式）

```bash
# 使用 xvfb 运行 browser-use
xvfb-run -a browser-use --browser real open "https://www.google.com"

# 或者使用 Playwright
xvfb-run -a npx -y playwright open --browser=chromium "https://www.google.com"
```

## browser-use 常用命令

### 基本操作

```bash
# 打开网页
browser-use open "https://www.example.com"

# 获取页面元素状态
browser-use state

# 点击元素（使用 state 输出的索引）
browser-use click 5

# 输入文本
browser-use input 3 "搜索内容"

# 截屏
browser-use screenshot

# 滚动
browser-use scroll down

# 关闭浏览器
browser-use close
```

### 浏览器模式

```bash
# Chromium 模式（默认无头）
browser-use --browser chromium open "URL"

# 有头模式（需要 X server）
browser-use --browser chromium --headed open "URL"

# 使用真实 Chrome
browser-use --browser real open "URL"

# 使用云端浏览器
browser-use --browser remote open "URL"
```

---

## Playwright 常用命令

```bash
# 安装 Playwright
npx -y playwright install chromium

# 打开网页（有头模式，需要 xvfb）
xvfb-run -a npx -y playwright open --browser=chromium "URL"

# 无头模式
npx -y playwright open --browser=chromium "URL"
```

## 故障排除

### 问题1：权限不足

```
/root/.nvm/versions/node/v22.10.0/bin/browser-use: 权限不够
```

**解决**：将 browser-use 复制到全局路径

```bash
cp /root/.nvm/versions/node/v22.10.0/bin/browser-use /usr/local/bin/
chmod +x /usr/local/bin/browser-use
```

### 问题2：找不到 node

```
/usr/bin/env: node: 没有那个文件或 directory
```

**解决**：使用完整路径或设置环境变量

```bash
# 方法1：使用完整路径
/root/.nvm/versions/node/v22.10.0/bin/node /path/to/script.js

# 方法2：设置 PATH
export PATH=$PATH:/root/.nvm/versions/node/v22.10.0/bin
```

### 问题3：Missing X server

```
ERROR: Missing X server or $DISPLAY
```

**解决**：

1. 安装 xvfb
2. 使用 `xvfb-run` 前缀
3. 或指定正确的 DISPLAY 值
