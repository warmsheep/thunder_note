# 当前联调契约总表

## 文档定位
本文档记录客户端与后端联调时的关键契约与漂移点。它不是完整 API 文档，而是用于理解当前联调状态的参考文档。

## 使用规则
- 若任务针对 Java 客户端与后端联调，先看本文件，再看 `API接口设计.md` 与对应代码。
- 本文件只写当前真实冲突与当前应遵循的契约，不写远期目标态。
- 当 Android API、DTO、Repository 或后端 controller/DTO 发生变化时，必须同步更新本文件。

### 5. 当前结论
- Android 主链当前实际调用到的后端接口，路径、HTTP 方法、请求体与响应体已经与后端 controller 保持一致。
- `GET /api/messages/stream`（SSE）当前后端已提供，但 Android 主链未消费；这属于“能力未接入”，不是“现有调用漂移”。
