# 当前联调契约总表

## 文档定位
本文档记录客户端与后端联调时的关键契约与漂移点。它不是完整 API 文档，而是用于理解当前联调状态的参考文档。

## 使用规则
- 若任务针对 Java 客户端与后端联调，先看本文件，再看 `API接口设计.md` 与对应代码。
- 本文件只写当前真实冲突与当前应遵循的契约，不写远期目标态。
- 当 Android API、DTO、Repository 或后端 controller/DTO 发生变化时，必须同步更新本文件。

## 当前真实契约

### 1. 认证
| 项目 | 当前真实后端 | 当前 Android 现状 | 结论 |
|------|--------------|------------------|------|
| 登录字段 | `username` | 登录 DTO / ViewModel / Repository / UI 文案已收敛为 `username` 语义 | 当前登录语义已一致 |
| 登录接口 | `POST /api/auth/login` | AuthApi 已存在 | Android repository 仍需真实接入 |

| 登出接口 | `POST /api/auth/logout` | AuthApi 已声明 | 需要真实接入 |
