# 技术栈选型

## 文档定位
本文档记录闪记项目的技术选型。需要注意：其中一部分已经在当前仓库实现，另一部分仍属于未来规划。

- 当前 Java 客户端已具备认证壳层、主壳层、闪记列表与聊天骨架，但尚未达到完整产品能力。

## 关键决策
### PostgreSQL 取代 MySQL
- 当前仓库真实数据库已经是 PostgreSQL
- 旧文档中出现的 MySQL 描述均应视为过时内容
- 数据库事实以 `application.yml` 与 Flyway 迁移为准

### Vue 取代 React
- 当前规划中的 Web 端以 Vue 3 为准
- 旧文档里出现的 React/Zustand 方案视为已淘汰方案
- 由于 Web 端尚未落地，实现前仍可复核，但当前文档统一以 Vue 方案描述

### SSE 取代 WebSocket
- 当前同步与实时提示的目标方向是 SSE
- 旧文档中若仍出现 WebSocket 长连接，应视为过时设计

## 维护规则

- 涉及 Web / iOS / Admin 的选型，必须明确标注"已选型，未实现"
- 如果未来技术栈变更，应优先更新本文件，再同步到架构和客户端文档
