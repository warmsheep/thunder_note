# 日志与可观测性设计

## 文档定位
本文档描述闪记当前与后续需要建立的日志、异常、诊断与可观测性规则，用于支撑联调、排障与上线后的问题定位。

## 当前事实
- 后端已有 `GlobalExceptionHandler`
- 后端当前日志级别在 `application.yml` 中配置：
  - `root: info`
  - `com.flashnote: debug`
- 当前仓库尚未建立完整的监控、告警、链路追踪方案

## 当前异常返回体系
- 统一响应包装：`ApiResponse`
- 当前错误码：0 / 40000 / 40100 / 40300 / 40400 / 50000
- 当前异常统一通过 `GlobalExceptionHandler` 输出接口错误响应

## 近期日志与诊断目标
- 让认证、闪记、消息、同步、文件这几条主线路径出现问题时可快速定位
- 让联调阶段能清楚判断是参数错误、认证失败、数据不存在，还是服务端异常

## 当前缺口
- 缺少统一日志格式说明
- 缺少关键业务事件日志清单
- 缺少同步链路专门的诊断字段与日志约定
- 缺少告警与监控设计

## 建议记录的关键事件
- 登录成功/失败
- token 刷新失败
- 文件上传失败
- sync push / pull / bootstrap 执行结果
- 消息发送失败
- 关键资源不存在或未授权访问

## 维护规则
- 当错误码体系、日志级别、关键异常处理逻辑变化时，必须同步更新本文件
