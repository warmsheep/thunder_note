# 页面设计规范

## 文档定位
本文档提供闪记当前原型与 Android 客户端可共用的 UI / UX 参考。它描述的是设计意图，不保证所有内容都已在代码中实现。

## 视觉方向
- 风格：轻量、清晰、强调内容本身
- 核心界面：登录、主页、消息、个人中心、设置
- 原型：以 `thunder-note-prototype.html` 为主要交互参考

## 设计原则
- 内容优先，弱化装饰性噪音
- 记录、消息、合集的入口层级要稳定
- 登录态、设置项、主题切换要有一致的交互路径
- 多媒体能力应遵循渐进增强，而不是一次性全部塞进主流程

## 当前使用方式
- 做 Android UI 调整时，同时参考本文件与 HTML 原型
- 做产品评审时，以原型验证结果为主，不把未实现页面直接当成交付能力

## 维护规则
- 本文档只保留视觉与交互规则
- 状态管理、localStorage、原型脚本实现细节不再写入此文档
- 如果未来设计系统稳定，再单独拆出颜色、字体、组件规范文档
