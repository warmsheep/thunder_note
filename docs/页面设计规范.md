# 页面设计规范

## 文档定位
本文档提供闪记当前原型与 Android 客户端可共用的 UI / UX 参考。它描述的是设计意图，不保证所有内容都已在代码中实现。

## 视觉方向
- 风格：轻量、清晰、强调内容本身
- 核心界面：登录、主页、消息、个人中心、设置
- 原型：以 `thunder-note-prototype.html` 为主要交互参考

## 设计原则
- 内容优先，弱化装饰性噪音
- 记录、消息、合集的入口层级要稳定
- 登录态、设置项、主题切换要有一致的交互路径
- 多媒体能力应遵循渐进增强，而不是一次性全部塞进主流程

## 当前使用方式
- 做 Android UI 调整时，同时参考本文件与 HTML 原型
- 做产品评审时，以原型验证结果为主，不把未实现页面直接当成交付能力

## 维护规则
- 本文档只保留视觉与交互规则
- 状态管理、localStorage、原型脚本实现细节不再写入此文档
- 如果未来设计系统稳定，再单独拆出颜色、字体、组件规范文档

- 正文优先使用 14sp
- 标题使用 16sp-24sp
- 辅助说明使用 12sp
- 时间戳等使用 11sp
- 所有文字大小必须引用 dimens.xml，禁止硬编码

## 按钮规范

### 主按钮（bg_button_primary_rounded）
- 高度：50dp
- 圆角：8dp
- 背景色：primary (#07C160)
- 文字色：white
- 文字大小：16sp (text_size_button_primary)
- 用途：登录、注册、提交等主要操作

### 次按钮
- 高度：wrap_content
- 背景：透明或 outline
- 文字色：primary
- 文字大小：14sp (text_size_button_secondary)
- 用途：取消、返回等次要操作

### 小按钮
- 最小高度：32dp
- 文字大小：12sp (text_size_button_small)
- 用途：编辑、刷新、清空等辅助操作

## 输入框规范

### 标准输入框（bg_input_rounded）
- 高度：50dp
- 圆角：8dp
- 边框：1dp border (#E5E5E5)
- 背景色：surface (#FFFFFF)
- 文字大小：14sp (text_size_input)
- 提示文字颜色：text_hint (#9C9C9C)
- 内边距：左右14dp，上下10dp

### Material TextInputLayout
- 使用 OutlinedBox 样式
- 文字大小：14sp (text_size_input)
- 圆角：继承默认样式

## 间距规范

### 页面边距
- 标准页面边距：16dp (spacing_page_padding)
- 登录/注册页面边距：左右24dp，上下40dp/20dp

### 列表项间距
- 垂直内边距：14dp (spacing_item_padding_vertical)
- 水平内边距：16dp (spacing_item_padding_horizontal)

### 组件间距
- 组件间距：8dp / 12dp / 16dp
- 卡片内边距：16dp
- 按钮与文字间距：8dp

## 布局文件规范

### 必须使用 dimens 引用的场景
所有布局文件（layout/*.xml）中的以下属性必须使用 dimens.xml 引用：
- `android:textSize` - 所有文字大小
- `android:layout_width` / `android:layout_height` - 图标、头像等固定尺寸
- `android:padding*` - 内边距（可选，复杂场景除外）
- `android:layout_margin*` - 外边距（可选，复杂场景除外）

### 示例
```xml
<!-- 正确 -->
<TextView
    android:textSize="@dimen/text_size_body"
    android:layout_width="@dimen/icon_size_avatar"
    android:layout_height="@dimen/icon_size_avatar" />

<!-- 错误 -->
<TextView
    android:textSize="14sp"
    android:layout_width="32dp"
    android:layout_height="32dp" />
```

### 禁止事项
- 禁止在布局文件中硬编码尺寸数值
- 禁止创建新的 dimens 用于单一场景
- 禁止绕过 dimens.xml 直接使用颜色值（应使用 color 引用）
