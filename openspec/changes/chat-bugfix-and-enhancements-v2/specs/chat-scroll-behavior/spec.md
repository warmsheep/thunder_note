## ADDED Requirements

### Requirement: 删除消息后保持聊天窗当前位置
系统 SHALL 在删除消息（单条或批量）后保持聊天窗口在当前滚动位置，不跳转到底部。

#### Scenario: 单条删除后保持位置
- **WHEN** 用户删除一条消息
- **THEN** 聊天列表更新后保持在删除前的大致位置，不滚动到底部

#### Scenario: 批量删除后保持位置
- **WHEN** 用户通过多选模式批量删除消息
- **THEN** 聊天列表更新后保持在删除前的大致位置

#### Scenario: 非删除场景仍滚动到底部
- **WHEN** 收到新消息或发送消息导致列表数据更新
- **THEN** 仍然自动滚动到底部（现有行为不变）
